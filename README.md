# 로잉버디 — 나만의 로잉 코치 (PWA)

목적 선택 → 맞춤 프로그램 생성 → 타이머·체크리스트로 운동 → 운동 후 기록 → 수행도·강도 평가 → 누적 기록 기반 추천.
iPhone Safari에서 쓰는 오프라인 웹앱입니다. 서버, 계정, 유료 API가 필요 없고 모든 기록은 기기에만 저장됩니다.

## 1. 설계

### 화면 구성

| 화면 | 내용 |
|---|---|
| 첫 실행 | 숙련도·주간 목표만 묻는 온보딩(심박 정보는 선택). 나머지는 설정에서 보완 |
| 홈 | 날짜, 캐릭터, "오늘은 어떤 로잉 훈련을 할까요?", 오늘의 추천(이유 포함), 목적 A–E, 시간 선택, 프로그램 미리보기(구간 타임라인 + 구간별 목표), 인터벌 직접 조정, 운동 준비 버튼 |
| 운동 진행 | 상단: 목적·경과/전체 시간·진행률 물길(보트가 이동). 중앙: 캐릭터, 현재 구간, 큰 타이머, 목표 강도/RPE/심박/페이스/SPM, 다음 구간. 하단: 큰 완료 체크, 일시정지·다음 구간·운동 종료, 전체 체크리스트 |
| 운동 후 기록 | "오늘 운동은 어떠셨나요?" RPE 1–10 큰 버튼, 컨디션, 통증 여부, 실제 시간·완료 여부·인터벌 수·메모, (펼침) Apple Watch 심박, (펼침) 로잉머신 거리·페이스·SPM·기기 정보. 직전 같은 훈련 값이 회색 안내로 표시 |
| 결과 | 운동 요약(입력값만), 훈련 수행도(항목별 점수·제외 사유·공식), 운동 강도 평가(측정값 vs 주관 RPE 구분), 지난 기록 비교, 데이터 근거 피드백 |
| 기록 | 월 달력(운동한 날 표시), 날짜별/월별 목록, 상세·수정·삭제, 타이머 없이 직접 기록 추가 |
| 분석 | 개인화 피드백·추천, 주간/월간 횟수, 누적 시간·거리(측정/추정 분리), 8주 지속성, 목적별 비중, 수행도·심박·페이스·RPE·안정시 심박 추이(누락 횟수 표시) |
| 설정 | 프로필, 안정시/최대 심박 + 카르보넨 구간표, 로잉 기준 기록, 백업·복원, 화면 테마, 데이터 삭제 |

### 데이터 구조 (IndexedDB `rowing-buddy`)

- `kv` 저장소: `profile`, `choice`(마지막 목적·시간), `active`(진행 중 운동), `draft`(입력 중인 기록), `theme`, `sound`, `lastBackup`, `lastDistSource`
- `workouts` 저장소 (키: `id`)

```js
profile = {
  schemaVersion, level: 'beginner'|'intermediate'|'advanced', birthYear, goal, preferredTime, weeklyTarget,
  restHR, maxHR,                      // 없으면 null
  twoKSec, pb500Sec, recentSteadyPaceSec, comfortPaceSec, preferredSpm,
  restHRHistory: [{ date, value }]
}
workout = {
  id, schemaVersion, createdAt, date: 'YYYY-MM-DD', goal, manual?,
  plan: { goal, level, minutes, plannedSec, key, repeat, intervalsPlanned, customPaceSec,
          segments: [{ id, phase, kind: 'steady'|'work'|'rest', name, durationSec, zoneId, desc,
                       target: { rpe, hr|null, pace|null, spm, hrNote } }],
          context: { hr, anchor } },
  segLog: [{ segId, actualSec, checked, status: 'done'|'partial'|'skipped'|'pending' }] | null,
  hrSnapshot: { rest, max, estimated } | null,   // 운동 당시 설정값 → 나중에 프로필을 바꿔도 과거 평가가 변하지 않음
  actualSec, completed, intervalsDone, memo,
  avgHR, maxHR, distance, distanceSource: 'machine'|'manual'|null, avgPaceSec, avgSpm, machineNote,
  rpe, condition: 'good'|'normal'|'tired'|'very_tired'|null, pain
}
```

입력하지 않은 값은 모두 `null`로 저장되고, 평가·통계에서 "누락"으로 처리됩니다.


## 2. 계산 기준과 근거

### 심박 구간 (모두 HRR 기준)

목표 심박 = 안정시 심박 + (최대 심박 − 안정시 심박) × 강도 비율

| 구간 | HRR | RPE(0–10) | SPM | 페이스(2,000m 페이스 대비) |
|---|---|---|---|---|
| 매우 가벼운 강도(회복) | 30–50% | 1–2 | 18–20 | +25~35초 |
| 저강도 지속 | 50–60% | 2–3 | 18–22 | +18~25초 |
| 중강도 유산소 | 60–70% | 3–4 | 20–24 | +12~18초 |
| 고강도 지속 | 70–85% | 5–6 | 24–28 | +5~10초 |
| 매우 높은 강도 | 85–100% | 7–9 | 28–32 | −3~+3초 |

- %HRmax와 섞지 않습니다(예: 안정시 60, 최대 190이면 HRR 60% = 138bpm, %HRmax 60% = 114bpm).
- 참고로 ACSM은 HRR 40–59%를 중강도, 60–89%를 고강도로 분류합니다. 이 앱의 구간 이름은 로잉 훈련용 이름이라 ACSM 용어와 1:1로 같지 않으며, 앱 설정 화면에도 이 점을 표시합니다.
- 최대 심박 실측값이 없으면 Tanaka 공식(208 − 0.7 × 나이)으로 추정하고, 10bpm 이상 다를 수 있다고 안내합니다. 실측값(Apple Watch 고강도 기록의 최고값 등)을 우선 사용합니다.
- 심박 정보가 없으면 RPE·시간·SPM으로 안내하며 모든 기능이 동작합니다.
- 3분 미만의 운동 구간에는 목표 심박을 표시하지 않습니다(심박 반응 지연). 3분 이상도 "참고용" 안내를 붙입니다.

### RPE

Foster 수정 CR-10(0–10) 세션 RPE를 사용합니다. 요청서의 묶음(1–2 매우 쉬움 … 9–10 매우 힘듦)은 이 척도와 맞도록 1–2 쉬움, 3–4 보통~약간 힘듦, 5–6 힘듦, 7–8 매우 힘듦, 9–10 거의 최대로 다듬었습니다(CR-10에서 5가 "힘듦"이기 때문).

### 페이스

심박으로 페이스를 계산하지 않습니다. 기준 기록 하나만 골라 "2,000m 평균 페이스"로 환산한 뒤 구간별 가감을 적용합니다. 우선순위: 2,000m 기록 → 최근 저강도 기록 3회 이상의 중앙값(−20초) → 입력한 지속 페이스(−20초) → 편안한 페이스(−22초) → 500m 최고 기록(+13초, 오차 큼). 기록이 없으면 페이스를 제시하지 않습니다.

### 프로그램 생성

- 웜업 ≈ 전체의 17%(2–10분), 쿨다운 ≈ 12%(2–8분). 회복 운동은 각 10%. 8분 미만은 1분씩.
- 지속형(A·B·E)은 본운동을 10분 단위 블록으로 나눠 체크리스트를 만듭니다. A는 초급 저강도/중급 이상 중강도, B는 저강도, E는 회복 구간.
- 인터벌(C): 초급 2분/2분(고강도), 중급 3분/2분(고강도), 고급 4분/2분(매우 높음). 시간이 짧으면 더 짧은 구성으로 내려가 최소 2회 반복을 확보. 반복 수에 상한이 있고, 남는 시간이 3분을 넘으면 저강도 지속 구간으로 채웁니다.
- 퍼포먼스(D): 초급 5분/2분(중강도), 중급 6분/2분, 고급 8분/2분(고강도) 페이스 유지 반복.
- 남는 몇 분은 쿨다운에 더해 **구간 합계 = 선택 시간**을 항상 보장합니다(테스트로 검증). 사용자가 인터벌을 직접 바꾸면 전체 시간을 다시 계산해 표시합니다.

### 훈련 수행도 (앱 자체 지표, 의학적 점수 아님)

`Σ(항목 점수 × 가중치) ÷ Σ(사용 가능한 항목 가중치) × 100`
시간 달성률 40, 체크리스트 완료율 30, 인터벌 수행률 20, 페이스 목표 10. 데이터가 없는 항목은 0점이 아니라 **계산에서 제외**하고 사유를 표시합니다. 강도가 높다고 점수가 오르지 않습니다.
페이스: 실제 평균이 "실제 수행한 구간 기준 계획 평균 페이스(거리 기준 평균)"보다 3초 이내로 느리면 100%, 이후 15초에서 0%까지 선형 감소.

### 운동 강도 평가

- 심박(측정값): 평균 심박 → HRR 비율로 환산 → 실제 수행 구간의 계획 강도(시간 가중 평균)와 비교, ±7.5%p 안이면 목표 범위. 인터벌은 세션 평균만 비교한다는 한계를 함께 표시합니다.
- RPE(주관): 지속형은 본운동, 반복형은 운동 구간의 계획 RPE 범위와 비교(±1 허용).
- 심박 강도로 예상되는 RPE와 기록한 RPE 차이가 3 이상이면 알려 줍니다.
- 운동 당시의 안정시·최대 심박을 기록에 함께 저장해 일관되게 평가합니다.

### 개인화 추천 규칙 (우선순위 순, 한 번에 하나만 적용)

1. 기록 3회 미만 → "개인화 분석을 위한 기록이 더 필요해요" + 일반 수준 추천
2. 최근 2회 중 통증·이상 증상 기록(7일 이내) → 회복 15분, 강도 증가 없음
3. 최근 7일의 마지막 3회 중 RPE 7 이상 2회, 또는 피곤함 2회, 또는 48시간 내 매우 피곤함 → 회복 운동
4. 36시간 이내 고강도(인터벌·퍼포먼스 또는 RPE 7 이상) → 저강도 지속 운동
5. 7일 이상 쉼 → 평소의 70% 시간으로 가볍게 재시작
6. 최근 7일 고강도 3회 이상 → 유산소 지속으로 균형 / 고강도 0회이고 중급 이상·피로 없음 → 인터벌 제안 / 그 외 평소 목표
7. 진행: 같은 목적·시간을 최근 3회 모두 수행도 90점 이상 + RPE 적정 → 지속형은 시간만 +5분, 반복형은 반복만 +1회(강도는 그대로, 시간과 강도를 동시에 올리지 않음)

추세 안내(분석 탭·홈): 같은 목적·시간 기록이 4회 이상일 때만 최근 2–3회와 그 이전 2–3회를 비교해 페이스 향상(2초 이상, RPE는 비슷하거나 낮음) 또는 비슷한 페이스에서 평균 심박 3bpm 이상 감소를 "가능성"으로 안내합니다. 추천은 언제든 홈에서 바꿀 수 있습니다.

## 3. 사용 방법

1. 처음 열면 숙련도와 주간 목표만 고르고 시작합니다.
2. 홈에서 목적(A–E)과 시간을 고르면 아래에 프로그램이 바로 만들어집니다. 인터벌·퍼포먼스는 "인터벌 직접 조정"에서 운동/회복 시간, 반복 수, 강도, 목표 페이스를 바꿀 수 있습니다.
3. "운동 준비하기" → 로잉머신에 앉은 뒤 "시작". 구간이 끝나면 자동으로 체크되고 소리로 알려 줍니다(종료 3초 전 짧은 소리).
4. "다음 구간"은 실제로 한 시간만 기록하고 넘어갑니다. "운동 종료"를 눌러도 수행한 기록은 보존됩니다.
5. 운동 후 RPE와 컨디션을 고르고, 필요하면 Apple Watch 운동 앱의 평균·최대 심박, 로잉머신의 거리·평균 페이스를 옮겨 적은 뒤 저장합니다. 빈칸이 있어도 저장됩니다.
6. 설정에 안정시 심박수와 2,000m 기록을 넣으면 목표 심박과 페이스가 표시됩니다.

입력 중에 앱을 닫거나 새로고침해도 진행 중인 운동과 작성 중인 기록이 복원됩니다.

## 4. iPhone Safari에서 실행

이 앱은 ES 모듈과 서비스 워커를 쓰므로 **파일을 직접 열면(file://) 동작하지 않고** 웹 주소(https)로 열어야 합니다. 가장 쉬운 방법은 아래 5번의 무료 배포 후 iPhone Safari에서 그 주소를 여는 것입니다.

컴퓨터에서 미리 확인하려면 프로젝트 폴더에서 `python3 -m http.server 8080` 실행 후 `http://localhost:8080`을 엽니다. (같은 Wi-Fi의 iPhone에서 `http://컴퓨터IP:8080`으로 열 수는 있지만, https가 아니라서 오프라인 기능은 동작하지 않습니다.)

## 5. 홈 화면에 설치 (PWA)

1. iPhone Safari에서 배포한 주소를 엽니다.
2. 공유 버튼 → "홈 화면에 추가" → 추가.
3. 이후 홈 화면의 로잉버디 아이콘으로 실행합니다. 한 번 연 뒤에는 인터넷 없이도 열립니다.

중요: iOS에서는 **Safari 탭과 홈 화면 앱의 저장소가 서로 분리**됩니다. Safari 탭에서 쌓은 기록은 홈 화면 앱에 보이지 않으니, 설치 후에는 홈 화면 앱만 쓰거나 백업 → 복원으로 옮기세요.

## 6. 무료 배포

**GitHub Pages (추천, 무료·계정만 필요)**
1. github.com 가입 → New repository → 이름 예: `rowing-buddy`, Public.
2. "uploading an existing file"을 눌러 이 폴더의 파일과 폴더(`index.html`, `manifest.webmanifest`, `sw.js`, `css/`, `js/`, `icons/`)를 끌어다 놓고 Commit.
3. Settings → Pages → Source: "Deploy from a branch", Branch: `main` / `(root)` → Save.
4. 1–2분 뒤 `https://아이디.github.io/rowing-buddy/` 주소가 생깁니다.

**대안**: Netlify Drop(app.netlify.com/drop)에 폴더를 끌어다 놓기, 또는 Cloudflare Pages. 모두 정적 파일만 올리면 됩니다.

앱 파일을 고친 뒤 다시 올릴 때는 `sw.js`의 `CACHE` 버전 문자열(예: `v1.0.1`)을 바꿔야 기기에서 새 버전으로 갱신됩니다. 기록 데이터는 기기에 있으므로 재배포해도 지워지지 않습니다.

Claude 계정이 없어져도 이 폴더(소스코드)와 백업 JSON만 있으면 계속 쓸 수 있습니다. 두 파일 모두 iCloud Drive나 GitHub에 보관해 두세요.

## 7. 백업과 복원

- 설정 → "백업 파일 저장": iPhone에서는 공유 시트가 열립니다 → "파일에 저장" → iCloud Drive 등에 보관. 파일명 `rowing-buddy-backup-날짜.json`.
- 설정 → "백업에서 복원": JSON 파일 선택. 기존 기록에 **추가**되며, 같은 기록(같은 id 또는 같은 시작 시각·목적·계획 시간)은 건너뛰어 중복되지 않습니다. 프로필은 바꿀지 물어봅니다.
- 기록이 3개 이상이고 14일 넘게 백업하지 않았으면 홈에 알림이 나옵니다.
- 백업 파일에는 `schemaVersion`이 있어, 이후 기록 구조가 바뀌어도 이전 백업을 변환해 불러옵니다.

## 8. 오프라인·데이터 보존의 한계 (솔직하게)

- 기록은 기기의 브라우저 저장소에만 있습니다. **기기 변경, Safari 방문 기록·웹사이트 데이터 삭제, 앱 삭제 시 사라집니다.** 백업이 유일한 보호 수단입니다.
- Safari 탭으로만 쓰면 iOS가 오래 방문하지 않은 사이트의 저장소를 정리할 수 있습니다. 홈 화면 앱으로 쓰는 편이 더 안전하지만, 저장 공간이 부족할 때 정리될 가능성은 남아 있습니다. 앱은 첫 저장 시 "영구 저장"을 요청하며 결과를 설정 → 앱 정보에 표시합니다.
- 화면이 꺼지면 iOS가 스크립트를 멈춥니다. 타이머는 실제 시각 기준이라 다시 켜면 정확한 시간으로 따라잡지만, 꺼져 있는 동안에는 소리 알림이 나지 않습니다. 앱은 운동 중 화면 꺼짐 방지(Wake Lock)를 요청하는데, iOS 버전에 따라 홈 화면 앱에서는 동작하지 않을 수 있습니다. 그럴 땐 운동 중에만 설정 → 디스플레이 및 밝기 → 자동 잠금을 길게 바꿔 두세요.
- 무음 모드에서는 알림음이 들리지 않을 수 있습니다. iPhone Safari는 진동 API를 지원하지 않습니다.
- 첫 접속은 인터넷이 필요합니다. 이후 오프라인으로 열립니다.

## 10. 구현 상태

**구현 완료**
- 프로필(최소 입력 시작, 이후 보완), 카르보넨 계산과 구간표, 최대 심박 추정 안내
- 목적 A–E, 10–60분·직접 입력(5–120분), 마지막 선택 기억
- 웜업·본운동·쿨다운 자동 생성(구간별 시간·목표 심박·RPE·페이스·SPM·회복·설명), 시간 합계 보장
- 인터벌 직접 조정(운동·회복 시간, 반복 수, 강도, 목표 페이스)과 재계산
- 실제 시각 기반 타이머, 일시정지·재개, 자동 구간 전환·체크, 체크 애니메이션, 진행률, 소리, 화면 꺼짐 방지 요청, 새로고침 복원
- 운동 후 기록(선택 입력, 이전 값 안내, 입력값 검증, 자동 임시 저장), 타이머 없이 기록 추가, 수정·삭제
- 훈련 수행도·운동 강도 평가(공식 공개, 누락 제외·사유 표시), 결과 리포트, 데이터 근거 피드백
- 같은 프로그램 비교, 달력·목록, 통계·추이·지속성, 규칙 기반 추천과 추세 안내
- IndexedDB 저장, JSON 백업·복원(중복 방지·버전 변환), PWA 설치·오프라인, 다크 모드, 캐릭터 SVG
